Chatbot - Embed Example

This page demonstrates how to embed the store AI chatbot into any website.

How to Embed the Chatbot

To embed the chatbot on your website, add the following code before the closing </body> tag:

<script>
  window.CHATBOT_WIDGET_CONFIG = {
    baseUrl: 'https://your-frontend-domain',    // URL where the chatbot widget is hosted
    apiUrl: 'https://your-backend-domain',      // URL of the backend API
    tenantPublicKey: 'replace-with-widget-key'  // Per-tenant public embed key (from admin / DB)
  };
  
  // Load the widget script
  (function() {
    const script = document.createElement('script');
    script.src = window.CHATBOT_WIDGET_CONFIG.baseUrl + '/widget.js';
    script.async = true;
    document.body.appendChild(script);
  })();
</script>
Note: When deploying to production, update the URLs to your actual hosted domain. Each site must set tenantPublicKey to the embed key issued for that tenant (literal string in the snippet you paste); the backend maps it via WIDGET_EMBED_KEYS_JSON.
